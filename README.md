# BlogNext

Blog desenvolvido com **Next.js**, com o objetivo de apresentar conteúdos introdutórios sobre desenvolvimento web para pessoas que estão começando na área.

## Tecnologias

* Next.js
* React
* TypeScript
* CSS Modules
* JSON

## Como começar

Clone o repositório:

```bash
git clone https://github.com/QueirozVictor/Blog-Next.git
```

Entre na pasta do projeto:

```bash
cd Blog-Next
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse:

```text
http://localhost:3000
```
